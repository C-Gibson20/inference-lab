# RUN-02 local mechanics stack

This document records the dependency and fixture selection for RUN-02. The
stack is a CPU-only mechanics fixture; it is not the production generator and
does not establish answer-quality or 24GB feasibility.

## Selected stack

| Component | Resolved version | Licence | Role |
| --- | --- | --- | --- |
| PyTorch | `2.8.0` | BSD-3-Clause | CPU tensor execution, greedy causal generation, and native past/KV state |
| Transformers | `4.55.4` | Apache-2.0 | Causal-model loading and generation interface |
| Tokenizers | `0.21.4` | Apache-2.0 | Fast tokeniser implementation used by the local fixture |
| Safetensors | `0.8.0` | Apache-2.0 | Safe serialisation of the fixture model weights |

The direct application dependencies are pinned in `pyproject.toml` and the
complete resolution is recorded in `uv.lock`. The transitive packages are not
part of the adapter identity unless they alter the selected runtime behaviour;
the lock file remains the reproducible installation record.

## Compatibility and locality evidence

- Python requirement: `>=3.13`; the smoke check ran on Python 3.13.
- Verified platform: macOS 26.6.2, arm64, CPU execution.
- The fixture loads from an explicit local directory with
  `local_files_only=True`.
- The offline smoke check passed with `HF_HUB_OFFLINE=1` and
  `TRANSFORMERS_OFFLINE=1`; it loaded the model, rendered a prompt, produced
  logits, and returned one native past/KV layer without a network request.
- No Hugging Face checkpoint, model registry, configured production model
  path, or GPU is required.

The selected Transformers API exposes `past_key_values` for the fixture's
causal model. If a supported dependency/platform combination stops exposing
usable native continuation state, this stack fails the RUN-02 selection gate
and must be replaced rather than reduced to tokeniser-only behaviour.

## Fixture provenance and identity

The fixture at
`tests/fixtures/backends/runtime/local_mechanics/` is generated by
`scripts/inference_lab/backends/create_local_mechanics_fixture.py`.

- Model: one-layer, one-head GPT-2-compatible causal model; 16-dimensional
  hidden state; 64-position declared context; vocabulary size 62.
- Tokeniser: project-owned BPE vocabulary with deterministic subword merges and
  explicit BOS, EOS, PAD, unknown, and role-marker tokens.
- Chat template: project-owned deterministic template stored in
  `chat_template.jinja`.
- Model weights: deterministically initialised with seed `20260902`, then
  stored as `model.safetensors`.
- Fixture artefacts contain no third-party model weights, document content,
  credentials, or network-fetched data.

## Reproduction

From the repository root, after `uv sync`, run the fixture generator:

```sh
UV_CACHE_DIR=/private/tmp/inference-lab-uv-cache \
uv run python scripts/inference_lab/backends/create_local_mechanics_fixture.py
```

Verify local-only loading and native cache availability:

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
UV_CACHE_DIR=/private/tmp/inference-lab-uv-cache \
uv run python -c 'from pathlib import Path; import torch; from transformers import AutoModelForCausalLM, AutoTokenizer; p=Path("tests/fixtures/backends/runtime/local_mechanics"); t=AutoTokenizer.from_pretrained(p, local_files_only=True); m=AutoModelForCausalLM.from_pretrained(p, local_files_only=True); x=t("hello world", return_tensors="pt"); y=m(**x, use_cache=True); assert y.past_key_values'
```

The adapter and focused acceptance suite are implemented in
`inference_lab.backends.runtime.local` and
`tests/inference_lab/backends/runtime/test_local.py`. Run the focused suite
offline from the repository root with:

```sh
HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 TOKENIZERS_PARALLELISM=false \
uv run pytest tests/inference_lab/backends/runtime/test_local.py
```

The full repository gate remains required for completion:

```sh
uv run ruff check .
uv run ruff format --check .
uv run pyright
uv run pytest
```
